Game Description
This project is a text-based Spider Solitaire game implemented in C/C++. Spider Solitaire is a classic single-player card game where players arrange cards in descending order (K, Q, J, ..., A) within tableau columns. The goal is to clear all cards from the tableau by forming complete descending sequences from King to Ace. Our game supports multiple difficulty levels (Easy, Medium, Hard) with different numbers of card suits and tableau columns, providing an authentic and engaging text-based solitaire experience.

Implemented Features & Mapping to Coding Requirements
a.Assigned card movement: Lets players move one or multiple valid cards by entering target columns.
b.Image-style card display: Shows cards in a visual, structured text interface for better gameplay experience.(ASCII)
c.Multiple difficulty levels: Easy, Medium, and Hard modes with different suits and card counts.
d.Undo move: Allows players to withdraw the latest move at any time.
